# Don't Text Your Ex

A 30-day no-contact coach — an interactive demo prototype.

It helps someone in the first days after a breakup resist texting their ex:

- **SOS — "Should I send this?"** Paste a draft message and get a verdict, the
  signals it spotted, and a rewritten unsent letter, plus a 90-second breathing reset.
- **Today** — no-contact streak, daily focus, mood check-in.
- **Plan** — a 30-day plan in four phases: Wilt, Root, Bud, Bloom.
- **Vault** — unsent letters, saved instead of sent.
- **Checklist** — breakup admin: mute/unfollow, shared subscriptions,
  stuff-return script, shared passwords.
